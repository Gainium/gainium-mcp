# Plan 002 — restart every copy on deploy

## Build order
1. `scripts/restart-extra-copies.mjs`: pure `selectExtraCopies(jlist, cwd, names)`
   + `parseJlist(stdout)`; a CLI `main` that reads `pm2 jlist`, restarts each
   selected id with `pm2 restart <id>` (no `--update-env`), exits 1 if any fail.
2. `package.json` `pm:restart` → `pm2 restart ecosystem.config.cjs && node scripts/restart-extra-copies.mjs`.
3. `.changes/` patch fragment.

## Contract decisions
- "This checkout" = the script's parent directory, compared after `realpath`
  so a symlinked deploy path still matches.
- Restart failures do not stop the loop; every copy is attempted, then exit 1.
- `pm2 jlist` stdout may carry a non-JSON banner line before the array; the
  parser starts at the first line beginning with `[`.

## Blast Radius
Deploy-time only. Changes nothing a running server does. Not in the npm
`files` list, so the published package is unaffected. Touches no Gainium API
contract. Other repos' pm2 processes are excluded by cwd.
